# Gerbtrace desktop releases

Download signed macOS and Windows installers from [Releases](https://github.com/newmatik/gerbtrace-releases/releases). This repository also hosts the update files used by the Gerbtrace desktop app.

The [Gerbtrace website](https://www.gerbtrace.com/features/desktop-app) has installation instructions and a download button for each platform. The application source code is maintained in a private repository.

If you installed v1.4.3 or earlier, install the latest version once from this public release page. Automatic updates will work from then on.
